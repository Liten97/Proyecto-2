# Proyecto-2

Landing page de **AireLibre**, una marca ficticia de tiras nasales.

Es un sitio estático (HTML, CSS y JavaScript sin dependencias):

- `index.html`: estructura y contenido (hero, beneficios, cómo funciona, precios, FAQ y CTA).
- `styles.css`: estilos responsive.
- `script.js`: menú móvil y carrito de demostración.

Para verla, abre `index.html` en el navegador o sirve la carpeta con, por ejemplo, `npx serve .`.
